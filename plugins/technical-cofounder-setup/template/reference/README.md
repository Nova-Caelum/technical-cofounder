# reference/

Material you bring in: documents, PDFs, spreadsheets, exports, notes, links,
screenshots, another project's code you want the team to read. Put it here and
the team can find it and cite it.

The team reads this folder and does not rewrite it. Its own output goes in
`work/` (what you build) or `worklog/` (what was decided).

A big import slows the project's drive map down: if one folder here grows to
hundreds of files, add it to `cutoff` in `.drivemap.toml` and the map will show it
as one line with a file count.
